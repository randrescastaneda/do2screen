# do2screen

## Objective

do2screen is a Stata package that allows users to review specific sections of a do-file directly in the Stata screen. It identifies how a variable is derived, generated, or modified by putting all relevant lines of code together in one piece for ease of use. It has three main functionalities: displaying lines where a variable is created or modified, searching for strings with configurable context, and displaying user-selected line ranges.

## Key Deliverables

- Stata .ado package
- .sthlp help file
- Example do-files
